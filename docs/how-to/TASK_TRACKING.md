## Blocker & Risiken

- **Blocker**: SQL Server Express 1GB RAM Limit

## Review-Zyklen

### Daily Standup Topics
- Gestern: Was wurde abgeschlossen?
- Heute: Welche Tasks sind geplant?
- Blocker: Was verhindert Fortschritt?

### Weekly Review
- KPI-Validierungs-Status
- Performance-Metriken
- Timeline-Adjustments

### Sprint Retrospective
- Was lief gut?
- Was kann verbessert werden?
- Action Items für nächsten Sprint
