# Dimensions-Views

Dimensions-Views für die OrderProcessing.

## Kritische Views
- `vw_dim_working_days` - Deutsche Holidays, WorkingDays-Calculation
- `vw_dim_provider` - Sentinel-Logik (ProviderGroupID IN (1, 2))
- `vw_dim_customer` - CustomerMasterData
- `vw_dim_service_type` - ServiceTypes
- `vw_dim_invoice_insurer` - Insurers-Informationen
