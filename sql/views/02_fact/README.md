# Fakten-Views

Fakten-Views für die OrderProcessing.

## Kritische Views
- `vw_fact_order` - Zentrale Order-Faktentabelle
- `vw_fact_order_intake` - OrderIntake-Faktentabelle
- `vw_fact_expiry` - Expiry calculation (180-day retention window, configurable)
- `vw_fact_invoice_provider` - Invoice-Provider-Verknüpfung
